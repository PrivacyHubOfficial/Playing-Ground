# Jailbreaking vs Rooting

## Jailbreaking

**Jailbreaking** is the process of removing software restrictions imposed on **Apple (iOS)** devices, such as iPhones and iPads.

It allows users to:

- Gain access to the underlying iOS operating system.
- Install applications and software not available through the App Store.
- Customize the device beyond Apple's default limitations.

---

## Rooting

**Rooting** is the process of obtaining **root (administrator)** access on **Android** devices.

It allows users to:

- Gain full control over the Android operating system.
- Modify or remove system applications.
- Install custom ROMs, kernels, and advanced utilities.
- Customize the device beyond the manufacturer's restrictions.

---

## Key Difference

- **Jailbreaking:** Used to gain privileged access on **Apple (iOS)** devices.
- **Rooting:** Used to gain privileged (root) access on **Android** devices.

Both methods provide greater control over a device's operating system but may reduce security, void warranties, and expose the device to additional risks.
